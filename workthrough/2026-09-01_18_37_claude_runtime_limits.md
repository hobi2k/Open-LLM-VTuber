# Claude Code 중단 원인 표시 개선

## 개요
Claude Code의 긴 코딩 작업이 50턴에서 강제로 끝나고 실제 종료 원인이 일반 오류 문구로 가려지는 문제를 수정했다. 도구 사용 모드에서는 SDK 기본 무제한 턴을 사용하고, 사용량 제한 등 Claude가 반환한 원인을 채팅에 표시한다.

## 주요 변경사항
- 코딩 작업의 하드코딩된 `max_turns=50` 제한 제거
- 오류 `ResultMessage`를 정상 응답으로 중복 출력하지 않도록 처리 순서 수정
- Claude SDK의 실제 종료 원인을 사용자 메시지에 보존
- 턴 제한과 사용량 제한 오류 흐름 회귀 테스트 추가

## 결과
- Ruff 검사 통과
- Claude/Codex/Hermes 관련 테스트 40개 통과
- 전체 테스트 98개 중 96개 통과
- 기존 ASR/TTS 설정 의존 테스트 2개는 현재 음성 비활성 설정 때문에 실패
