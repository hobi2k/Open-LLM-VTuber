# 네이티브 세션 채팅 이력 복원

## 개요
OpenCode, Claude Code, Codex, Hermes의 기존 세션을 선택할 때 원본 대화와 코딩 작업 이력을 VTuber 채팅 타임라인으로 복원하도록 구현했다. 원본 저장소는 수정하지 않고 읽기 전용으로 파싱한다.

## 주요 변경사항
- 개발한 것: 네 런타임 공통 세션 이력 API와 저장 형식별 파서
- 복원한 것: 사용자·AI 텍스트, 추론, 커맨드, 파일 변경, 도구 실행 상태
- 보호한 것: 로컬 요청 제한, Codex rollout 경로 검증, 최근 1,000개 렌더링 제한

## 결과
- Ruff 통과
- 런타임 관련 백엔드 테스트 64개 통과
- 실제 로컬 네 런타임 세션 스모크 테스트 통과
