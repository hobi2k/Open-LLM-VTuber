# 새 런타임 세션 제목 반영

## 개요
새 대화에서 미리 지정한 제목을 실제 런타임 세션이 생성되는 순간 원본 세션에 반영하도록 구현했다. OpenCode, Claude Code, Codex, Hermes 모두 같은 예약 제목 규칙을 사용한다.

## 주요 변경사항
- 런타임 설정 스키마에 `new_session_title` 추가
- OpenCode 세션 생성 요청에 제목 직접 전달
- Claude Code, Codex, Hermes 세션 ID 생성 직후 원본 저장소의 제목 갱신
- 제목 반영 시점이 늦는 런타임은 다음 요청에서 자동 재시도
- 설정 직렬화와 런타임 팩토리 전달 경로 보완

## 결과
- 백엔드 전체 테스트 111개 통과
- Ruff 린트 및 변경 파일 포맷 검사 통과
- 네 런타임 제목 반영 회귀 테스트 추가
