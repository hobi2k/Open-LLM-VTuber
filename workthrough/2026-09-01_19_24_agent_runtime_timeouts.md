# 에이전트 응답 타임아웃 제거

## 개요
Codex 코딩 작업이 정확히 300초 후 강제 종료되는 문제를 수정했다. OpenCode, Claude, Codex, Hermes의 실제 응답 대기 경로가 장기 작업을 시간으로 중단하지 않도록 통일했다.

## 주요 변경사항
- Codex app-server 초기화, 응답, 권한 및 사용자 입력 대기의 절대 타임아웃 제거
- Hermes ACP 프롬프트의 300초 절대 타임아웃 제거
- OpenCode 스트림의 응답 읽기 타임아웃 제거
- Codex 무제한 응답 대기 회귀 테스트 추가

## 결과
- Ruff 검사 통과
- 네 에이전트 런타임 관련 테스트 56개 통과
