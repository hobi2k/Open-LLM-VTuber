# 네이티브 세션 제목 표시 수정

## 개요
Codex와 Claude Code 세션 목록이 최초 프롬프트를 제목처럼 표시하던 문제를 수정했다. 각 런타임에서 사용자가 지정한 실제 세션 제목을 최우선으로 사용한다.

## 주요 변경사항
- 수정한 것: Codex `threads.name`을 자동 생성 `title`보다 먼저 사용
- 수정한 것: Claude Code 세션별 `custom-title.json`의 `customTitle` 반영
- 추가한 것: 실제 저장 구조를 재현한 제목 우선순위 회귀 테스트

## 결과
- 세션 카탈로그 테스트 11개 통과
- Ruff 검사 및 포맷 검사 통과
- 실제 로컬 Codex 및 Claude Code 사용자 지정 제목 확인

## 다음 단계
- 다른 런타임에서 사용자 지정 제목 저장 형식이 바뀌면 카탈로그 파서를 함께 갱신
