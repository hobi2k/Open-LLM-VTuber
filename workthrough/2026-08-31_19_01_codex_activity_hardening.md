# Codex 코딩 활동 표시 안정화

## 개요
Codex의 내부 JSONL 툴 이벤트가 채팅에 그대로 노출되고, 긴 MCP 결과에서 응답 스트림이 중단되던 문제를 수정했다. 툴 입력과 결과는 사람이 읽을 수 있는 명령·경로·텍스트만 전달하도록 정제했다.

## 주요 변경사항
- 개발한 것: 브라우저/MCP 결과의 텍스트 블록 추출 및 32MB JSONL 스트림 지원
- 수정한 것: `code`, timeout, 중첩 결과 JSON이 사용자 화면에 노출되던 문제
- 개선한 것: 100KB 단일 이벤트와 raw JSON 비노출 회귀 테스트 추가

## 결과
- Python lint 통과
- 에이전트 활동 테스트 2개 통과
- CLI 에이전트 테스트 20개 통과
- 실제 Codex 명령 실행·파일 수정·diff·최종 응답 확인
