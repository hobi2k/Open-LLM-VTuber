# 코딩 활동 타임라인 구현

## 개요
코딩 모드에서 네이티브 에이전트의 추론, 커맨드 실행, 파일 변경, 실행 결과, 최종 응답을 순서대로 표시하도록 이벤트 파이프라인과 채팅 UI를 확장했다. OpenCode, Claude Code, Codex, Hermes의 서로 다른 출력 형식을 하나의 활동 이벤트로 정규화했다.

## 주요 변경사항
- 개발한 것: 실행 중 상태를 완료 또는 실패 결과로 제자리 갱신하는 코딩 활동 카드
- 수정한 것: 커맨드, 경로, 입력, 출력, unified diff를 WebSocket으로 전달하는 공통 이벤트 규격
- 개선한 것: 활동 이벤트가 대화 목록의 최신 메시지 미리보기를 덮어쓰지 않도록 텍스트 메시지만 선택
- 보강한 것: Claude, Codex, OpenCode 스트림과 Hermes 세션 DB 복원 회귀 테스트

## 결과
- 백엔드 전체 55개 테스트 통과
- 프런트 타입 검사와 관련 파일 ESLint 통과
- 웹 프로덕션 빌드와 Electron macOS arm64 패키징 성공
- 통합 서버가 새 정적 자산을 정상 제공하는 것 확인

## 다음 단계
- 각 CLI가 새 버전에서 이벤트 스키마를 바꿀 경우를 대비해 실제 출력 fixture를 계속 보강
- 장기 대화 기록에서도 활동 카드를 복원해야 한다면 활동 이벤트 영속화 추가
