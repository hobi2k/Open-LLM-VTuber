# 네이티브 런타임 이미지 입력

## 개요
웹소켓으로 받은 이미지 첨부를 OpenCode, Claude Code, Codex, Hermes의 네이티브 멀티모달 입력 규격으로 전달하도록 연결했다. 사용자 로컬 음성 설정 때문에 흔들리던 오디오 테스트도 기본 설정 템플릿 기준으로 격리했다.

## 주요 변경사항
- 개발한 것: data URL 검증 및 Claude SDK 이미지 블록, Codex app-server 이미지 입력, Hermes ACP 이미지 블록 변환
- 유지한 것: OpenCode의 기존 file part 입력 및 네이티브 세션 재개 동작
- 수정한 것: 이미지가 텍스트로만 오인되던 안내 문구와 웹소켓 이미지 타입
- 개선한 것: 오디오 기본값 테스트가 사용자 `conf.yaml` 상태에 의존하지 않도록 격리
