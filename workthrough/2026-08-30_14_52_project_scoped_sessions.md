# 프로젝트별 네이티브 세션 전환

## 개요
AI 런타임 설정에서 프로젝트 폴더를 바꾸면 세션 범위를 자동으로 현재 프로젝트로 전환하고, 이전 프로젝트의 선택된 세션을 해제하도록 개선했다.

## 주요 변경사항
- 프로젝트 변경을 런타임별로 감지해 `현재 프로젝트` 범위를 자동 선택
- 프로젝트 경로의 구분자와 끝 슬래시를 정규화
- 선택한 프로젝트의 하위 폴더에서 생성된 세션도 함께 표시
- 기존 `전체 프로젝트` 범위는 사용자가 필요할 때 다시 선택 가능

## 검증 결과
- OpenCode `enigma`: 해당 프로젝트 세션 40/74개만 표시
- OpenCode 상위 `personal/`: 하위 프로젝트 세션 58/74개 표시
- Codex `opencode`: 해당 프로젝트 세션 45/3,438개 표시 및 기존 세션 선택 성공
- TypeScript, 변경 파일 ESLint, 웹 프로덕션 빌드 통과
