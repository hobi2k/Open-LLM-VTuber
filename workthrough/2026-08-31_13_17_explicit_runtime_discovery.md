# 명시적 AI 런타임 검색

## 개요
AI 런타임 설정을 여는 동작과 OpenCode, Claude Code, Codex, Hermes 탐색을 분리했다. 사용자가 검색 버튼을 눌렀을 때만 실행 파일, 연결 상태, 모델, 프로젝트와 세션을 갱신한다.

## 주요 변경사항
- 설정 조회와 저장에서 자동 실행 파일 및 서버 프로브 제거
- `미확인`, `검색 중`, `사용 가능`, `사용 불가` 상태와 명시적 검색 버튼 추가
- 현재 입력 중인 실행 경로와 워크스페이스를 검색 요청에 반영
- 백엔드 준비 전 `Failed to fetch`가 남는 앱 시작 순서 수정
- 영어, 일본어, 중국어 런타임 검색 문구 추가

## 결과
- 백엔드 회귀 테스트 36개 통과
- 프런트엔드 타입 검사와 ESLint 통과
- 웹 및 macOS Electron 프로덕션 빌드 성공
- 실제 앱에서 Live2D, 명시적 검색, 네 런타임 경로와 세션 로딩 확인

- 대규모 Codex 세션 목록의 가상 스크롤 적용 검토
