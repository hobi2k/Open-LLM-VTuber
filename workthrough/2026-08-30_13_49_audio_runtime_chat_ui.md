# 채팅·음성·런타임 UI 개선

## 개요
채팅 화면을 메시지·추론·도구 실행 상태가 명확히 구분되는 작업형 UI로 개편했다. 비어 있던 TTS 설정과 현재 ASR 모델 정보를 노출하고, VTuber 서버 연결 실패 시 사용자가 주소와 런타임 설정을 직접 복구할 수 있게 했다.

## 주요 변경사항
- 개선한 것: 채팅 말풍선, 상태 헤더, 입력창, 마이크·중단 버튼과 설정 서랍의 시각 체계
- 개발한 것: TTS 엔진·음성 조회 및 변경 API와 설정 UI
- 개발한 것: ASR 엔진·SenseVoice 모델 정보 표시
- 수정한 것: 런타임 API 오프라인 시 캐시된 oMLX·모델·프로젝트·세션 유지 및 수동 서버 URL 복구
- 개선한 것: 데스크톱·좁은 창에서 텍스트 줄바꿈과 설정 서랍 반응형 동작

## 결과

- ✅ Electron 프로덕션 렌더러 빌드 성공
