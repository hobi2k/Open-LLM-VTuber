# 런타임 세션 이름 변경

## 개요
OpenCode, Claude Code, Codex, Hermes 세션의 이름을 설정 화면에서 변경하고 각 런타임의 네이티브 저장소에 유지하도록 구현했다. 선택한 세션 옆의 편집 버튼으로 이름을 바꾸며 저장 후 전체 세션 목록을 즉시 갱신한다.

## 주요 변경사항
- 개발한 것: 로컬 전용 세션 이름 변경 API와 편집 다이얼로그
- 수정한 것: OpenCode API, Claude `custom-title.json`, Codex 상태 DB, Hermes CLI별 저장 처리
- 개선한 것: 런타임 중지 상태의 로컬 저장 보완과 오류 표시, 영어·일본어·중국어 문구

## 결과
- 백엔드 세션·카탈로그 테스트 16개 통과
- 프런트엔드 타입 검사와 Electron 프로덕션 빌드 통과
