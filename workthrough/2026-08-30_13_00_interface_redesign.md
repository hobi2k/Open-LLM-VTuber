# 데스크톱 인터페이스 재설계

## 개요
OriginKit의 조절 가능한 컴포넌트 구성과 정돈된 시각 계층을 참고해 설정 패널과 채팅 사이드바를 재설계했다. 긴 실행 경로, 모델명, 세션 ID와 다국어 문구가 잘리지 않도록 레이아웃과 줄바꿈 규칙을 함께 보완했다.

## 주요 변경사항
- 설정 탭을 아이콘이 포함된 3열 구조로 정리하고 중성적인 다크 팔레트와 명확한 포커스 상태를 적용했다.
- 런타임 상태, 4개 CLI 선택, 모델·프로젝트·대화 선택과 고급 설정의 정보 계층을 정돈했다.
- 긴 입력값은 전체 값 미리보기를 제공하고 드롭다운 항목과 보조 문구가 줄바꿈되도록 수정했다.
- 채팅, reasoning, 도구 상태, 사용자 이름과 긴 문자열이 사이드바 폭을 넘기지 않도록 보완했다.
- 540px 설정 서랍이 440px 부모에서 잘리던 문제와 768px 이하에서 사이드바가 사라지던 문제를 Electron QA 중 발견해 수정했다.

## 결과
- `npm run typecheck` 통과
- 변경 TS/TSX 파일 ESLint 통과
- `git diff --check` 통과
- Electron 및 웹 프로덕션 빌드 통과
- Electron 900x670, 700x600, 영문·일문, 긴 경로·세션·모델 목록 시각 검증 완료
- macOS 앱 ad-hoc 서명 및 `codesign --verify --deep --strict` 통과
