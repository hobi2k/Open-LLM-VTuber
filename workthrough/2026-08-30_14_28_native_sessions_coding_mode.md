# 네이티브 세션과 코딩 모드

## 개요
OpenCode, Claude Code, Codex, Hermes가 자체적으로 만든 세션까지 VTuber 설정에서 검색하고 이어갈 수 있게 했다. 캐릭터 대화와 코딩 작업의 시스템 프롬프트 및 도구 권한을 분리했다.

## 주요 변경사항
- 개발한 것: 전체 프로젝트/현재 프로젝트 세션 범위, 전체 기록 검색, 캐릭터 대화/코딩 작업 모드
- 수정한 것: 세션 50개 제한, OpenCode 단일 프로젝트 조회, Hermes 빈 ACP 세션 노출
- 개선한 것: 대용량 목록 렌더링 제한, 원래 작업 폴더 복원, WebGL 미지원 환경의 Live2D 예외 방지

## 결과
- 백엔드 단위/통합 테스트 37건 통과
- Ruff, TypeScript, ESLint 검사 통과
- 웹 프로덕션 빌드 성공
- 실제 카탈로그 확인: OpenCode 72개, Codex 3,438개, Claude 21개, Hermes 16개
- 브라우저에서 세션 범위 전환, 전체 검색, 작업 폴더 복원, 코딩 모드 권한 연결 확인
